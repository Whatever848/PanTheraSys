# PanTheraSys 集成步骤

## 1. 把源码放入项目

建议放到：

```text
D:\PanSoftware\PanTheraSys\src\dobot_trajectory\
```

复制以下文件：

```text
DobotSftpClient.h/.cpp
DobotTrajectoryManager.h/.cpp
DobotDashboardClient.h/.cpp
DobotTrajectoryRunner.h/.cpp
```

如果你已有 Dashboard 客户端，可以先不集成 `DobotDashboardClient.*`，只集成 Manager + Runner。

## 2. 修改构建系统

### CMake 项目

把 `cmake/DobotTrajectoryModule.cmake` 复制到项目 cmake 目录，在主 `CMakeLists.txt` 中：

```cmake
include(cmake/DobotTrajectoryModule.cmake)
add_executable(PanTheraSys ...)
dobot_trajectory_attach(PanTheraSys)
```

### qmake 项目

把 `qmake/dobot_trajectory.pri` 复制到项目目录，在 `.pro` 中：

```qmake
include(src/dobot_trajectory/dobot_trajectory.pri)
```

并配置 libssh2 include/lib 路径。

## 3. 找到图片 2 对应的 UI 控件

让 Codex 在项目中搜索：

```text
预设轨迹
轨迹控制
Z轴对齐
StartDrag
StopDrag
comboBox
refresh
```

需要定位到：

- 控制器 IP 输入框；
- “刷新”按钮；
- 轨迹文件下拉框；
- 运行轨迹按钮；
- 停止按钮或现有停止逻辑；
- 日志输出函数。

## 4. 刷新按钮接入 SFTP

刷新按钮逻辑必须从控制器读取：

```text
/dobot/userdata/project/process/trajectory/
```

不是读取本地目录。

## 5. 运行按钮接入 StartPath

运行按钮只传文件名：

```text
StartPath(filename.csv,isConst=0,multi=1.00,sample=50,freq=0.200)
```

不要写成：

```text
StartPath(/dobot/userdata/project/process/trajectory/filename.csv,...)
```

## 6. 验收标准

1. 在厂家软件中新录制一条轨迹，保存后厂家列表出现 5 条；
2. 在 PanTheraSys 点击刷新，下拉框也出现 5 条；
3. 选择新轨迹，点击运行，Dashboard 返回 `0,{...}` 或 `0,{}`；
4. `RobotMode()` 在运行中返回 7，完成后回到 5；
5. 中文文件名能显示并运行；如果不行，检查 Dashboard 发送是否使用 UTF-8。
