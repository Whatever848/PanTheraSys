# 故障排查

## 1. 刷新后仍只有 4 条

检查日志中 SFTP 实际读取目录是否为：

```text
/dobot/userdata/project/process/trajectory/
```

如果代码读取的是本地目录，必须改掉。

## 2. SFTP 连接失败

重点检查：

- 控制器 IP 是否正确；
- PC 是否能 ping 通控制器；
- 端口 22 是否开放；
- 账号密码是否是 root/dobot；
- 防火墙是否拦截；
- 机械臂与电脑是否在同网段。

## 3. StartPath 返回非 0

重点检查：

- 运行时只传文件名，不传完整路径；
- 文件确实在 `/dobot/userdata/project/process/trajectory/`；
- 机械臂已使能；
- 当前无报警；
- 没有处于拖拽、暂停、急停、错误状态；
- 已获得 TCP 控制权。

## 4. 中文文件名运行失败

检查 Dashboard 发送函数是否使用 UTF-8：

```cpp
socket.write(command.toUtf8());
```

不要使用本地 8-bit 编码或 GBK。

## 5. libssh2 编译不过

Windows/CMake 推荐 vcpkg：

```powershell
vcpkg install libssh2:x64-windows
cmake -B build -S . -DCMAKE_TOOLCHAIN_FILE=D:/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
```

如果使用 qmake，需要在 `.pro` 或 `.pri` 中加入 include/lib 路径，并链接 `libssh2` 和 Windows 的 `ws2_32`。
