# 手动测试步骤

1. 打开厂家 DobotStudio Pro，在“设置 -> 轨迹文件 -> 轨迹复现”中确认当前列表数量。
2. 在厂家软件中新建轨迹，拖拽录制，保存为新的 `.csv` 文件。
3. 厂家列表应出现新文件。
4. 打开 PanTheraSys，确认控制器 IP 为 `192.168.5.1` 或实际 IP。
5. 点击“刷新”。
6. PanTheraSys 下拉框应出现新文件，并且总数量与厂家列表一致。
7. 选择新文件，点击运行。
8. 日志应出现类似：

```text
StartPath(xxx.csv,isConst=0,multi=1.00,sample=50,freq=0.200)
0,{},StartPath(...);
```

9. 运行中轮询 `RobotMode()`，应看到运行中为 7，完成后回到 5。
10. 点击停止，应发送 `Stop()` 并返回 `0,{}`。
