# 厂家源码定位说明

resources.zip 中与轨迹复现相关的关键位置：

```text
resources/app.asar
└─ src/windows/MainWindow/components/DeviceSettings/TrackRecording/
   ├─ trackRecording.vue
   ├─ track.vue
   ├─ index.vue
   └─ trackFileHandler.ts
```

关键链路：

```text
trackRecording.vue
  refresh()
    -> getRetraceFileList()
      -> formatRetraceFileList()
        -> vm.getDragTeachFileList(portName)

vm.ts
  getDragTeachFileList(portName)
    -> dobotlink.sendSambaRequest('readDir', {
         portName,
         url: '/developOnly/process/trajectory'
       })

sftp.ts
  sambaUrltoFTP('/developOnly/process/trajectory')
    -> '/dobot/userdata/project/process/trajectory'
```

SFTP 登录参数：

```text
host: 控制器 IP
port: 22；本机 127.0.0.1 时厂家代码用 2022
username: root
password: dobot
```

厂家排序逻辑：

```text
普通文件名：保留 readDir 返回顺序
时间格式 yyyy-MM-dd-HH-mm-ss.csv：放在普通文件之后，按时间倒序
```

所以 PanTheraSys 需要做的是：

1. 用 SFTP 读取 `/dobot/userdata/project/process/trajectory/`；
2. 过滤 `.csv`；
3. 按厂家规则排序；
4. 刷新到下拉框；
5. 运行时调用 `StartPath(文件名.csv,...)`。
